# R4 八家將獨立人物圖

本包含八張獨立透明 PNG，可分別載入與移動。編號依 R4 原合圖由上到下、每列由左到右排列。

## 圖片規格

- 每張為 512 × 640 px，RGBA PNG，真正透明背景。
- 保留原圖各位人物的主要臉譜、服色、帽型、法器、扇子與向右跨步姿態。
- 採同一透明畫布與腳底基線 y=592；錨點為 `[0.5, 0.925]`。
- 依原合圖人物的相對高度輸出，保留高帽與一般帽型的差異，帽沿、法器和鞋尖皆有留白。
- 本次由 imagegen 逐位透明編修後等比例輸出，並非逐像素無損裁切。完整提示詞附於 generation-prompts.json。

## 使用

依 manifest.json 的八個新 ID 分別載入。本包提供單張人物靜態圖，不含步行動畫影格。
原本的 event_bajiajiang_patrol 是八人合圖；若遊戲仍引用該 ID，需將巡街隊伍改為載入本包八個人物 ID，分別設定各自位置。
本包未改動遊戲程式或覆蓋舊合圖，未驗證遊戲中的實際載入效果。

## 檢查

八張均已逐位比對來源造型，並檢查帽頂、鞋尖、扇沿與法器完整，沒有鄰人殘片。
檔案檢查包含尺寸、RGBA 透明通道、四邊透明、安全留白、單一主要人物輪廓及 SHA-256。
