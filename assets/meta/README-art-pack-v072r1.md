# 鯤島爭仙：香火伏妖傳 · v0.72 美術整合包 R1

## 直接使用

雙擊 `index.html` 可搜尋、分類檢視及開啟每一張素材。雙擊 `kundao-v072-art-inline.html` 可開啟已內嵌圖片的遊戲。遊戲不需要另外下載字型或圖片。`kundao-v072-art-external.html` 是開發用外部素材版本，需要本機靜態伺服器，不建議直接用 file:// 開啟。

本包以本輪上傳的 `kundao-phase1-inline-v072(1).html` 為整合基礎，並核對 `kundao-package-v072.zip` 的程式及設定。

## 美術處理方式與來源

這不是 437 張逐張獨立 AI 新生成的原畫。製作包含：原附件圖像的材質與輪廓統整、使用者範例圖的獨立去背及編排、本對話生成地形與特效圖的拆分，以及塔、封印、筊杯、龍脈、地表、介面等局部重繪與合成。每個 ID 的來源與方法均記錄於 `metadata/asset-changes.csv` 與 JSON，沒有將舊檔複製後聲稱全部全新 AI 生成。

`artwork/` 是工作主圖，不表示每張都有新的高解析細節。從範例拆出的細小圖與既有圖像衍生版本存在原始解析度限制；2× 主要提供縮放與整合便利，並不等同重新繪製兩倍細節。

## 已實際處理的項目

封印中央統一使用可辨識的「封」字。塔提供中性、陽、陰三套各一至九重，共 27 張逐重素材；每重都有獨立屋簷與窗層，底座、寶珠不算重數。功法與法器名稱沿用附件，選圖依目前程式的塔法器 `w.lvl`，夾在 1–9，沒有改成讀取上限五層的被動功法。

陰陽區分使用金橘／紫冷色，加上日月徽記、窗內火／月形以及對應法器造型。龍脈改為接地裂土與立體氣帶構圖，不把範例中的整片山水景觀當作等比例地圖地形。小妖彈、五營兵、護身劍、狀態圖示及新增靈獸技能圖示均有單張素材。

新地形包含完整樹木、灌木、苔岩、草叢、切株、倒木、水草、燈籠柱與紅磚牆；來源中尚未接入 v0.72 的物件保留在素材庫，沒有偷偷增加地圖的碰撞障礙。

筊杯以半月形木筊重繪：聖筊一凸一平、笑筊兩平、陰筊兩凸。字型僅用於轉成圖片的字形，包內沒有字型檔。

## 地圖比例與渲染

比例設計以角色可見身高約 60 世界像素對應 1.75 公尺作為假設，見 `metadata/proportion-and-render.json` 與 `previews/proportion_sheet.png`。這是插畫遊戲的相對比例，不是寫實人體或具有現實量測依據的神魔尺寸。

草叢與小岩低於角色，燈籠柱、廟與樹木高於角色；相同類型的物件使用統一的顯示尺度與腳底錨點。塔是法器顯化的鎮煞小塔，不是可供人居住的九層樓房；層數增加時高度確實增加。特效顯示大小受原程式的作用範圍參數控制，沒有增加傷害範圍。

渲染改為地表、地面效果、按接地 Y 座標排序的物件與角色、狀態／投射物、HUD。角色走到樹後時，近處遮擋樹木會半透明。地板材質比例依原圖像尺寸計算，內嵌與外部版一致。HUD 及選單改為統一紙色、金框與朱紅視覺。

## 沒有改動的部分

敵人資料、AI、傷害、法器機制、屬性計算、轉世、存檔結構、地圖生成位置及碰撞判定均保留。`04-engine.js` 唯一非渲染模組差異是加入 `navigator.maxTouchPoints` 的觸控能力判定，屬於手機 UI 適配，不是玩法變更。原始模組比對記錄見 `metadata/gameplay-source-check.json`。

乩童與第七關鏡像等素材在原版尚未實作的功能，本包仍不會把它們變成新關卡或可選道途。沒有新建敵人種類或將範例概念圖中的其他神獸冒充既有首領。

## 檔案與驗證

`assets/manifest.json` 保留全部原有 ID 與標準 w/h，另附 @2x 位置、透明範圍與錨點資訊。靜態檢查包括：PNG 可讀性、RGBA、尺寸、空白檔、原始 ID 覆蓋、平鋪邊界、@2x 倍率與 JavaScript 語法。原包的 `tools/validate-assets.js` 隨包附上。

瀏覽器測試使用 Chromium，涵蓋圖片載入、建立暫存測試帳號、道途選單、開局、移動、暫停、兩張地圖渲染及 390×844 手機視窗。環境禁止 file/http 導航，因此測試將同一份 HTML 直接送進瀏覽器記憶體，並使用暫存 localStorage 替身；交付 HTML 本身沒有此替身。沒有完成使用者裝置的 file:// 實測、完整十分鐘通關、所有法器組合或長期存檔測試。詳細結果見 `metadata/browser-validation.json`。

`previews/renderer_controlled_scene.png` 是實際渲染器的受控驗收場景，物件由測試程式安排，不是假稱自然遊玩的畫面。其他 UI 與開局圖也來自瀏覽器測試；單張聯絡表與比例板則是素材合成檢視，不是遊戲截圖。

## 後續修改

更換 `assets/` 的同名標準 PNG 後，可在本資料夾執行 `python tools/rebuild_inline.py` 重建單檔 HTML。需要嵌入 @2x 圖時使用 `--scale 2`，檔案會明顯變大。預設整合 HTML 採標準尺寸，2× 與工作主圖仍完整保留在素材包。
