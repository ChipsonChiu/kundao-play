交付日期：2026-11-07（日本時間）

已檢視原包全部 **611 個素材 ID**，並將美術範圍固定為台灣民俗文化、道教傳統信仰、台灣在地民間傳奇，以及各原住民族的神話與祖靈信仰。以原劍修少年、符修少年的圓臉點眼和短身比例，重新繪製六道途全部既有主角，並特別重製藥修少年。

## 開啟方式

完整解壓縮後，以瀏覽器開啟根目錄的 **index.html**。不需安裝套件或連線，即可查看首頁構圖、八景提案、全部素材搜尋與修訂規格。請保留 assets、masters、metadata、previews、notes 與 index.html 的相對位置。

首頁「道途圖鑑」可查看六道途人物；「八景巡禮」可切換場景並放入角色；「素材總覽」可按名稱、ID、類別及製作方式篩選，並切換棋盤、深色、白色背景檢查透明邊緣。

## 主要調整

- 六道途主角統一圓臉、點眼、約 2.5–3 頭身與霧面紙感。保生藥師青年改陶研缽、木杵、藥草與布藥袋；偶師使用實際操演的布袋戲偶；宋江武者與乩童使用各自輪廓。
- 神明、地方傳奇與人形鏡像同步整理。必要的神格冠帽、鬍鬚和持物保留，去除原先的華麗光盤、珠寶感與重金裝飾。大士爺等有文獻依據的角、獠牙和儀式造型，不因外觀相似就判為日本元素。
- 器物改為木、竹、素陶、石與舊銅；陰陽特效改為土黃朱砂與低彩靛灰的乾筆圖形，保留用途和輪廓辨識。
- 首頁、門樓、小祠、廟宇及介面融入台灣廟埕與聚落材料。八款完整場景分別轉譯八位藝術家的色彩和空間語彙；不重用原作圖片像素。

## 尺寸與使用範圍

原包 611 個標準 PNG 的寬高維持不變；首頁為 1920 × 1080，新增八景為 1536 × 1024。新版透明素材只在輸出標準圖時作等比縮放與裝框，不用色彩替換或拼貼冒充重新繪製。主角建議依可見高度 60 世界像素與腳底錨點配置，詳見 proportion-and-render.json。

兩張原有地表另行重製，仍用於平鋪；八張完整場景是獨立背景原畫。劍潭、鶯歌對應原包已有關卡，其餘六款為新增美術概念。原包沒有可玩遊戲程式，本次不包含戰鬥、碰撞、解鎖、存檔或關卡接入的執行驗證。

文化設定已明確收斂，但保留圖像屬本輪目視審查判斷，並非文化來源的自動鑑定。各原住民族的神話與祖靈信仰保留各自脈絡；本次未把缺乏族群依據的祖靈造型新增成通用敵人或裝飾。

1,238 張 PNG 均已完成檔案校驗與完整解碼，原 ID、尺寸、來源映射與雜湊全部通過檢查。預覽頁的資料、連結及 JavaScript 語法另經 13 項靜態檢查，全部通過。R3.1 的圖像異動核對確認只有大稻埕場景，其他 618 個素材 ID 的標準圖與工作圖內容雜湊與 R3 一致。
