## 來源與製作方式，請先閱讀
**本包不是所有素材逐張獨立新生成的高解析原畫。** 本輪圖像工具實際產生的是總覽圖；可用部分已切分、去背、清理並依規則命名，另含使用者附件拆分、既有 437-ID 素材庫中的保留圖、局部零件繪製、合成及鏡像衍生。每一項的 `method`、`source`、`native_source_size` 與 `note` 記錄在 `metadata/catalog.json`、CSV 與素材庫頁面。

工作圖保留來源可得的細節；總覽中約數十至一百餘像素的小圖，放大不會變成真正高解析重繪。沒有以放大、換色、相容別名或同檔不同尺寸冒充獨立全新設計。兩個仍有明顯接合問題的少女合成稿及其鏡像已排除，不列入交付數量。

因此，本包完成的是 **v0.72 全 ID 覆蓋、可用單張整理與擴充角色概念**；「所有項目全部逐張全新高解析重繪」仍未達成。

## 去背與尺寸
標準圖均為 RGBA PNG，其中 603 張含實際透明像素。以下 8 張為完整平鋪地表或開場背景，刻意保留畫面本體，不把地板刪成空白：
stage_jiantan_bg_tile, title_bg, terrain_grass_tile_b, stage_yingge_bg_tile, terrain_path_tile, terrain_stone_floor, terrain_water_edge, terrain_water_tile。

UI 的紙色面板、卡片與按鈕本體屬物件，不應被當背景去掉；物件外側透明。白色鬼魂、白衣與高光也不使用「所有白色一律刪除」的方法。

原 437 個 ID 的標準 w/h 已核對保留。新增 ID 使用小寫英文及底線，副檔名 `.png`。PNG 的透明留邊不是世界大小；角色建議以可見高度約 60 世界像素作共同基準，使用 `content_bounds` 與腳底錨點換算。原物件相對比例規格保留在 `metadata/proportion-and-render.json`，屬遊戲美術比例假設，不是神魔的現實量測。

## 神明與角色的狀態
`implemented`：現行可選道途；`planned_phase2`：企劃已列名但尚未實作的道途；`candidate_phase3`：偶師候選；`planning_concept`：擴充概念；`planned_phase7`：依企劃製作的鏡像衍生。

神明是遊戲風格化創作，不是宗教神像造型考據定稿。原企劃文化研究附錄提到的所有背景神祇，不等同已定案的登場角色名單，本包不宣稱逐位全數畫完。

`landscape_dragon_vein` 是圖鑑山水插畫；實際地圖龍脈使用 `fx_vein` 與其階段圖，避免把整片山景縮成角色旁的一個小道具。

## 未變更遊戲
這次只交美術包，沒有修改 HTML、傷害、職業解鎖、神明權重、碰撞、轉世或存檔。新增 `deity_*`、`player_songjiang*`、`player_oushi*` 等 ID 不會因放入資料夾就變成可選功能；需由遊戲端接入。本包不是新的可玩遊戲版本。

## 驗證
`metadata/validation.json` 記錄所有標準 PNG 的可讀性、RGBA、尺寸、空白檔、命名、原 ID 覆蓋、透明像素與相同檔案別名檢查。結果錯誤數為 0。

主角、神明、物件與特效預覽已檢視，但本輪沒有進行瀏覽器遊戲測試、完整通關、所有特效組合或動畫逐幀驗收。`previews/` 是交付 PNG 的實際合成聯絡表，不是假稱遊戲截圖。
