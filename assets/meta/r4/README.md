## 最新修訂

- 乩童的男女造型、動作、鏡像與投射物一致使用尪仔標。金圈與槍的新方案未收錄。
- 尪仔標七階命名：新營標、三鳳標、太子宮標、南鯤鯓標、代天標、東隆標、馬鳴標・本命。依台灣地名規則編製，原九線 63 名維持定案。
- 三昧真火沿投擲路徑留下持續傷害火帶，初始每段存續 0.5 秒，隨升級延長；未指定的增幅與傷害保留空值。
- 藥修青年重新生成，宋江武者與乩童少女、各自鏡像及所需動作補齊。正式五道途共十款外觀；偶師只保留候選。
- 首頁、七鯤身、隱藏慶中元與補充地景統一原包描線和色塊，畫家參照只作用於色彩與空間。大稻埕指定《南街殷賑》，遊戲夜景另作清楚標示。
- 神明改為法器與非人形光影；陰神用廟影與燈籠。祖靈盟約分族處理，矮靈不描繪。

## 檔案結構

| 路徑 | 用途 |
| --- | --- |
| `assets/` | 遊戲標準尺寸 PNG 與 manifest |
| `masters/` | 選定原生 PNG |
| `previews/` | 主角、場景、乩童、信仰及新圖檢視表 |
| `metadata/` | 全素材索引、別名、名稱、來源、需求覆蓋與效果契約 |
| `docs/background-r4.md` | 合併最新更正後的完整背景設定 |
| `docs/source-background-original.md` | 使用者提供的背景原文 |
| `docs/art-direction.md` | 美術規範與文化範圍 |
| `docs/integration.md` | 尺寸、錨點、分層、動作與相容接入說明 |

## 使用前要知道

本包完成的是美術與設定素材，沒有取得或修改遊戲原始碼。PNG、索引、尺寸與需求覆蓋均依實際檔案檢查；遊戲碰撞、傷害與引擎接入未宣稱已驗證。暗視野 PNG 是霧邊圖層，完整遮黑須搭配遊戲端遮罩。

只收錄選定版本。被取代的金圈、槍、偏寫實草稿與舊神明本尊未混入正式圖片。提示詞與參考檔名保留於生成紀錄；曾作為編修輸入的中間版本不因同名而被視為本包最終圖。
