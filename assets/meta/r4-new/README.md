## 土地公廟的 28% 陰影

精確版本為 `composites/shrine_unoffered_28pct.png` 與 `runtime/shrine_unoffered_28pct.svg`。SVG 使用新生成的暗燈基底，將 sRGB 色彩乘以 `0.72`，等同於加上 `28%` 中性黑色陰影，alpha 維持原值，透明背景不受影響。成品 PNG 直接由該 SVG 匯出；已比對全部 alpha 與不透明區色值，僅有 8-bit 四捨五入誤差。

`shrine_unoffered_base.png` 保留正常廟身亮度，供分層使用；`shrine_unoffered_visual.png` 是依 28% 陰影方向生成的方便檢視版本，並非逐像素數值校正稿。需要嚴格 28% 時，請使用 SVG 或對基底套用 `render-contract.json` 的公式一次。不要再對已暗化的視覺稿重複疊加陰影。

祭祀後可直接使用 `composites/shrine_offered_with_halo.png` 或 `runtime/shrine_offered_with_halo.svg`，也可將 `shrine_offered_base.png` 與獨立暖光圖層合成。燈籠位置已換算為標準 PNG 座標；光暈強度 0.36 是本次美術起始設定，可配合實際底圖調整。

## 接入時需保留的設定

- 尪仔標是平滑薄紙卡與劍獅印刷，已移除鬆餅感的波浪厚邊及交叉格紋。投射弧線及迴返機制不在這次修改範圍。
- 腳下狀態為 256×128，anchor `[0.5, 0.5]`，先畫地面效果再畫主角。圖樣中心留空。
- 三段火為 256×96，共用裁切與 anchor `[0.5, 0.875]`。路徑火焰的初始存留仍為 **0.5 秒**；沒有新增各段時間或升級曲線，三張圖不表示每張各 0.5 秒。
- 偶師男女維持候選定位。角色為 128×160，腳底 anchor `[0.5, 0.95]`。
- 橋段三態共用 520×320；坑道三態共用 520×400。各組採同一幾何匯出範圍，以維持切換位置。生成圖仍可能有局部線條差異，不視為逐像素一致的動畫幀。
- 新坑道坍方圖包含整個坑口，與 R4 舊的 320×240 坍方石堆範圍不同；請依檔名對照選用整組狀態，不直接假設舊碰撞範圍相同。
